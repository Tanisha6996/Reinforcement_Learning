# Reinforcement Learning Labs

A collection of Python implementations exploring fundamental concepts and algorithms in Reinforcement Learning (RL), including multi-armed bandits, Markov Decision Processes, temporal-difference learning, model-based RL, and policy gradients.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Gym
- TensorFlow and Keras
- Pygame

## Key Concepts

- Exploration vs. exploitation
- Multi-Armed Bandits
- Markov Decision Processes (MDPs)
- Policy Evaluation and Improvement
- Q-Learning
- Temporal-Difference Learning (TD(0))
- Model-Based Reinforcement Learning
- Value Iteration
- Policy Gradient Methods
- REINFORCE Algorithm

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

Install the required libraries:

```bash
pip install numpy matplotlib gym tensorflow pygame
```

Run an individual lab:

```bash
python <filename>.py
```

## Purpose

These labs provide hands-on practice with reinforcement learning algorithms, environment design, policy learning, and visualization.
